# Data Analysis Strategies: course repo (instructions for any AI agent)

This is a pandas course. One case, the Titanic dataset: who survived, and why.

- `pt/` has the notebooks in Portuguese. `en/` has the same notebooks in English.
- Notebooks have no saved outputs. Run the cells to see results.
- Answer in the language the learner writes in.
- Explain before you edit anything. Say what you will change and why.
- Do not edit the learner's notebooks unless asked. Prefer showing code in the chat.
- After you suggest code, run the cells to check that it works, and show the result.
- Keep code simple: pandas, NumPy, Seaborn, Matplotlib. Short lines, plain words.
- Do not add private data or secrets to the repo.
